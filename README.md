# TGift

Вьювер Telegram NFT-подарков с Lottie JSON-предпросмотром.

TGift показывает обычные и NFT-подарки Telegram через [`api.changes.tg`](https://api.changes.tg): можно выбрать подарок, модель, фон и символ, посмотреть итоговый предпросмотр и быстро открыть или скопировать JSON-эндпоинты.

## Возможности

- каталог подарков Telegram с поиском;
- предпросмотр обычного подарка и NFT-варианта;
- Lottie JSON-рендер моделей и оригинальных подарков;
- отдельный вьювер всех моделей, фонов и символов;
- фон NFT с выбранным символом как паттерном;
- сортировка слоев по редкости или названию;
- копирование API-ссылок для JSON-ассетов.

## Стек

- React
- TypeScript
- Vite
- lottie-web
- api.changes.tg

## Запуск

```bash
npm install
npm run dev
```

Сайт будет доступен по адресу, который покажет Vite, обычно `http://127.0.0.1:5173/`.
